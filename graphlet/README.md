# graphlet

graphlet draws graphs in Claude Code: in Claude's replies, and in other mods.

```
/plugin install graphlet --marketplace nsodhi-cmu/claude-code-graphlet
```

The repository's [README](https://github.com/nsodhi-cmu/claude-code-graphlet#readme) shows an example, and says what graphlet draws, its settings, and its limits. Its [docs](https://github.com/nsodhi-cmu/claude-code-graphlet/tree/main/docs) say how it works, and how a mod builds on it.
