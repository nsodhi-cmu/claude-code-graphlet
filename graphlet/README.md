# graphlet

graphlet is a Claude Code mod that draws graphs, nodes and the links between them, inside Claude Code. It is for other mods to build on: a mod hands it a graph, and graphlet draws it in that mod's pane, scrolls it, and says which node the person picked.

```
/plugin install graphlet --marketplace nsodhi-cmu/claude-code-graphlet
```

The repository's [README](https://github.com/nsodhi-cmu/claude-code-graphlet#readme) says how a mod uses it and what it does with the access a mod has.
